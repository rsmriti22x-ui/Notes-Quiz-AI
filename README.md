# Notes-Quiz-AI
Paste notes, get a summary and a practice quiz. Built with Flask + HTML/CSS/JS, running on Nebius Token Factory with an NVIDIA Nemotron model.

Run
pip install -r requirements.txt
set NEBIUS_API_KEY=your_key        (Windows)   # export NEBIUS_API_KEY=your_key on Mac/Linux
set NEBIUS_MODEL=<nemotron model id from Token Factory>
python app.py

Open http://127.0.0.1:5000
